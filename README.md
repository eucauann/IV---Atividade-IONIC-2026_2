# Portal do Aluno UCSal

Protótipo em Ionic 1 + AngularJS para a atividade de Programação Mobile.

## Como rodar

```bash
npx http-server www -p 8080
```

Depois é só abrir a porta 8080 no navegador (no Codespaces aparece na aba "Ports").

## Estrutura

- `www/js/app.js` – módulo e rotas ($stateProvider)
- `www/js/services` – dados mockados (Auth, Noticias, Aluno, Financeiro)
- `www/js/controllers` – controllers de cada tela
- `www/templates` – telas HTML
